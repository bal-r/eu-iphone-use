# Requirements

- A Mac with full Xcode, initial components installed, and support for your iPhone's iOS version.
- Codex desktop and Codex CLI with local plugin/MCP support.
- Python 3.9 or later.
- Node.js 20.19+, 22.12+, or 24+, with npm 10+.
- Your own iPhone, a USB data cable, and your own Apple account for signing.

No jailbreak, separately running Appium server, or iPhone Mirroring is required.

Apple's free Personal Team supports personal-device testing with seven-day provisioning. Rebuild and reinstall the runner when provisioning expires. [Apple account guidance](https://developer.apple.com/help/account/basics/about-your-developer-account).
